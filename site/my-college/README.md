# 吉大电子资料库：课程目录界面

所有定制放在本目录，服务器通过站点覆盖机制加载，无需构建。设计参考开放课程网站的课程目录组织方式，不依赖 MIT OCW 的 Hugo、React 或 CMS。

- `index.html`、`assets/site/home.js`：校园背景、实时统计、课程入口和最近分享。
- `browse.html`、`search.html`、`assets/site/catalog.js`：默认列出课程；按真实分类树推导年级与学期，支持名称 / 拼音搜索、资料收录筛选、排序、两种视图和每页 12 门课程。地址栏保存筛选状态。
- `assets/site/resource-search.js`：复用上游的资料搜索，保留类型、范围、层次及分页；无关键词时提示输入关键词，不遍历全库资料。
- `node.html`、`assets/pages/node.js`：根据课程实际资料生成类型筛选，支持年份、排序；保留合集、批量下载、关注、审核员管理及移动功能。筛选后只选择和下载当前结果。
- `assets/app.js`：覆盖上游公共布局，加载全站主题、统一“课程目录”导航文字，移除顶部导航的“⭐ 开源”和“教程”入口及页脚快捷链接行；源代码链接放在页脚站点说明后。同步上游时需核对该覆盖文件。
- `assets/site/tree-picker.js`：保留 `/browse?pick=1` 上传分类选择行为。
- `assets/site/theme.css`：全站统一浅灰绿底、深青色导航、白色卡片和表单；教程、审核、提醒及账号和上传页面共用课程目录的配色，保留警告、错误与成功状态色。由公共布局模块加载，直接访问和软导航均生效。
- `assets/site/learning.js`、`learning.css`：课程卡片和课程页面专用布局。软导航不会替换 head，因此课程布局入口会按需加载这份样式；全站配色由 `theme.css` 维护。

课程目录只读取已有分类和资料元数据。新增课程、资料审核、文件存储与下载继续由原有后端处理。没有添加数据库字段或更改资料文件，也没有将学习资料纳入 Git 仓库。

## 验证与发布

运行仓库的 `scripts/check-web.mjs`、`scripts/check-rules.mjs`；额外将 `web/` 与本站覆盖目录合并到临时目录，对合并结果做 JS 语法、导入与资源路径检查。浏览器测试应覆盖目录 / 课程 / 搜索的软导航、筛选与刷新、分页、空结果、接口失败重试、上传分类树和访客登录跳转。测试数据应放仓库外，不能部署。

使用已有 `bash scripts/deploy-web.sh` 发布。它只替换网页和站点资源，并重启服务，不迁移数据目录。

本阶段没有新增教学大纲、教师或学分等数据库信息；课程概览仅显示实际路径和资料数量。页面仍遵守本站现有登录访问规则。
