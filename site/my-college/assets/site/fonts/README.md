Derived from [GenSen Rounded 2 TC Regular](https://github.com/ButTaiwan/gensen-font) by ButTaiwan (based on Source Han Sans), under SIL OFL 1.1. See `OFL.txt`.

Source SHA-256: `86b50c3309e232bf51e11c75dbd2f3b37f1efef7e1c02ed221e1d3387d6c38f1`

The glyph outlines are unchanged. The webfont is renamed Campus Rounded and converted to WOFF2 with fontTools 4.60.2. The entire upstream character map is retained across three non-overlapping subsets: site UI/Latin/punctuation, remaining GB2312 characters, and extended characters. CSS unicode ranges load only the required subsets. All 773 Chinese characters in the current site UI are present. Regular is the supplied weight; browser synthesis provides existing bold headings. Unusual unsupported characters use the system fallback. No runtime font CDN is used.
